For Claude in VS Code, for Claude in the cloud chat, and for the owner.
Written 2026-11-14 by Claude in the cloud chat. It lives in
`HOLO-Claude/`, beside `JOURNAL.md`. Newest first.

The owner, 2026-11-14: "Here is a proposal: I post the photos of the
process here, from the iPhone. You can upload them to GitHub yourself,
start a PHOTOS.md for you in VS Code, add an update to the README; so

be pulled from GitHub into HOLO-Claude."

## How a photo travels

1. The owner sends the photos from his iPhone to the cloud chat, in the
   HOLO project.
2. Claude in the cloud puts them in `HOLO-Claude/photos/<date>/`, under
   the iPhone's own names (`IMG_2909.jpg`), writes the batch at the top
   of this file, a line a photo, and pushes to `main`.
3. Claude in VS Code runs `git pull` at the start of every session
   (README, Working rules) and reads the newest batch below.

- The copies are the chat's: 1512 × 2016, no EXIF, so no time and no
  place in them. The originals stay on the iPhone; a post is made from
  the original.
- A photo is a look, not a measure. With no ruler in the frame, a number
  read off one is est.
- What a run's photos show goes into `JOURNAL.md` (Seen), by file name.
- The machine camera's frames go to `eyes/`, not here (`ARTIST.md`, Eyes).
- No other artist's work here (README).
