(`app/colors.html`, its data `app/src/colorlib.js`), measured off the photos below. The owner, 2026-11-08: "I want the names on the
physical jars to be written the same as on the LAB tab, real 3"; "README — sorry, I do not quite understand. Build a COLORS tab next to
LAB, so that our library is there."
